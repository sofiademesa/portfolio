# Event photos

Drop your org / event photos in this folder using the filenames below (.jpg).
A badge, ticket or row only shows the camera icon + photo preview once its photo exists, so you can add them a few at a time.

More than one photo for an event? In index.html, list them with commas:
`data-photo="events/spellbound.jpg, events/spellbound-2.jpg"`

Tip: keep each photo around 1200px wide / under ~300 KB so it loads fast on phones.
