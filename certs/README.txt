  ccna-introduction-to-networks.png  -> Cisco · CCNA: Introduction to Networks
  intro-to-data-science.png          -> Introduction to Data Science
  javascript-essentials-1.png        -> Cisco · JavaScript Essentials 1
  responsive-web-design.png          -> freeCodeCamp · Responsive Web Design
  git-training.png                   -> Simplilearn · Git Training
  intro-to-figma.png                 -> Simplilearn · Introduction to Figma
  it-fundamentals.png                -> CompTIA · IT Fundamentals+ (ITF+)

Until an image is added, clicking the card shows a placeholder telling you which file to add.
